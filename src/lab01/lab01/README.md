# Задание 1
### Запрашиваю у пользователя имя и возраст через input, вложенные в f строку. Таким образом выполняю всё за 1 строчку.
```print(f'Привет, {input('Имя: ')}! Через год тебе будет {int(input('Возраст: '))+1}.')```

2 задание: Через input запрашиваю у пользователя числа a и b. На случай неразумности пользователя заменяю ',' на '.', чтобы не выдало ошибку (python читает float именно с точкой). Вывожу результаты с точностью до 2 знака после запятой через f строчку.

3 задание: считываю ввод, аналогично 2 заданию исправляю ',' на '.', далее через приложенные в задании формулы произвожу рассчёты. Вывожу через f строчки, делая отступы, чтобы текст получился ровным по правому краю, как в примере к заданию.

4 задание: считываю ввод в минутах. Для оптимизации кода произвожу рассчёт сразу в выводе, при помощи f строчки: для получения количества часов нацело делю количество минут на 60. Для получения количества минут беру остаток от деления изначального количества минут на 60, оставляя ровно 2 символа после часов с помощью метода, который был приведён в тексте задания.

5 задание: считываю ввод ФИО пользователя в 1 строчку. Для оптимизации произвожу все операции с введённым ФИО сразу же в выводе, через f строки и генераторы. Зная, что заглавные буквы всегда идут впереди, я делю ФИО по пробелам, а затем беру из полученных элементов первый (нулевой) символ. Таким образом, через склеивание получаю инициалы. Для получения длины ФИО сначала сплитую (чтобы избавиться от лишних пробелов), затем склеиваю в одну строчку ровно с 1 пробелом между частями ФИО. Использую len для получения количества символов.
