### 1. read_text

def read_text(path: str | Path, encoding: str = "utf-8") -> str:
    """
    Открыть файл на чтение в указанной кодировке и вернуть содержимое как одну строку.

    Пример выбора другой кодировки (например, для Windows-файлов):
        text = read_text("document.txt", encoding="cp1251")

    Args:
        path: Путь к файлу (строка или объект Path).
        encoding: Кодировка файла (по умолчанию "utf-8").

    Returns:
        str: Содержимое файла.

    Raises:
        FileNotFoundError: Если файл не найден (всплывает автоматически).
        UnicodeDecodeError: Если указанная кодировка не подходит (всплывает автоматически).
    """
    p = Path(path)
    # По ТЗ FileNotFoundError должен всплывать сам при чтении
    return p.read_text(encoding=encoding)
```

### 2. write_csv

def write_csv(rows: Iterable[Sequence], path: str | Path,
              header: tuple[str, ...] | None = None) -> None:
    """
    Создать или перезаписать CSV-файл с разделителем ",".

    Args:
        rows: Данные для записи (итерируемый объект из кортежей или списков).
        path: Путь, по которому будет сохранен файл (строка или объект Path).
        header: Заголовок таблицы (по умолчанию None).

    Raises:
        ValueError: Если строки в rows имеют разную длину.
    """
    p = Path(path)
    rows_list = list(rows)
    
    # Краевой случай: данных нет и заголовка нет -> пустой файл
    if not rows_list and header is None:
        ensure_parent_dir(p)
        p.write_text("", encoding="utf-8")
        return

    # Определение ожидаемой длины строки
    if header is not None:
        expected_len = len(header)
    else:
        expected_len = len(rows_list[0]) if rows_list else 0

    # Валидация длин строк
    for r in rows_list:
        if len(r) != expected_len:
            raise ValueError(
                f"Несоответствие длины строки. Ожидалось элементов: {expected_len}, "
                f"найдено: {len(r)} в строке {r}"
            )

    ensure_parent_dir(p)

    with p.open("w", newline="", encoding="utf-8") as f: 
        w = csv.writer(f, delimiter=",")
        if header is not None:
            w.writerow(header)
        w.writerows(rows_list)
```
### 2.1. ensure_parent_dir
```
def ensure_parent_dir(path: str | Path) -> None:
    """Создает родительские директории для указанного пути, если они не существуют."""
    Path(path).parent.mkdir(parents=True, exist_ok=True)
```

1.Парсинг аргументов (argparse)
<pre>
    Программа считывает переданные флаги командной строки. На основе количества переданных файлов в аргументе --in выполнение разветвляется на два сценария:
        • Один файл (Базовый режим): анализируется один указанный источник, результаты выводятся в консоль и записываютсяв один CSV-файл (задается через --out).
        • Несколько файлов (Режим ★): включается пакетная обработка. Скрипт генерирует детальный пофайловый отчёт (--per-file) и объединённый сводный отчёт (--total).
</pre>
2. Чтение и извлечение токенов
```
    • Для каждого файла вызывается функция read_text с указанной кодировкой (по умолчанию utf-8, с возможностью переключения на
     cp1251). Полученная сырая строка передаётся в функцию tokenize(), которая внутри вызывает normalize(), очищает текст от
     управляющих символов, приводит к нижнему регистру, заменяет букву ё на е и разбивает текст на слова по регулярному выражению
     \w+(?:-\w+)*.
```
3. Подсчёт и агрегация частот
```
	• В базовом режиме функция count_freq() собирает токены в словарь частот {слово: количество}.
	• В многофайловом режиме статистика собирается локально для каждого файла, после чего частоты слов суммируются в общем
     словаре total_freq без повторного прогона процедур токенизации.
```
4. Сортировка данных
```
+	• Для базового и сводного отчётов используется функция top_n() с параметром n=len(freq). Она упорядочивает пары по ключу
     (-count, word), обеспечивая сортировку по убыванию частоты, а при совпадении чисел — по алфавиту слов.
	• Для пофайлового отчёта список кортежей (имя_файла, слово, count) сортируется встроенным методом .sort() с составным
     ключом key=lambda x: (x[0], -x[2], x[1]), что гарантирует группировку по имени файла (по алфавиту), внутри файла — по
     убыванию частоты, а при равенстве частот — по алфавиту слов.
```
5. Форматирование и вывод
```
	• В консоль: функция print_pretty_table() динамически вычисляет максимальную ширину колонок на основе переданных данных,
     строит более-менее красивую таблицу и выводит упорядоченный топ-10.
	• В директорию: функция write_csv() преобразует списки в прямоугольную таблицу и сохраняет её в файлы с соответствующими
     заголовками колонок.
```
Обработка ошибок:
```
    • Файл не найден: перед началом обработки скрипт проверяет существование всех путей через Path.exists(). Если хотя бы один
     файл отсутствует, программа выводит понятное сообщение в sys.stderr и завершает работу с кодом sys.exit(1).
    • Пустой файл: если файл не содержит текста, функция tokenize() возвращает пустой список. Скрипт обрабатывает эту структуру
     без ошибок выхода за границы массивов, а итоговый CSV-файл корректно создаётся и содержит только строку с заголовками колонок.
```
Параметры запуска:
```
    • --in — Пути к одному или нескольким исходным .txt файлам.
    • --out — Путь к итоговому CSV для базового режима (по умолчанию: data/lab04/report.csv).
    • --per-file — Путь к пофайловому CSV для режима ★ (по умолчанию: data/lab04/report_per_file.csv).
    • --total — Путь к сводному CSV для режима ★ (по умолчанию: data/lab04/report_total.csv).
    • --encoding — Кодировка для чтения файлов (по умолчанию: utf-8).
```
